# مملكة ناصر

شركة ذكاء اصطناعي متخصصة في صناعة وإنتاج المحتوى الإسلامي الرقمي الهادف والموثوق.

المنصة الأساسية في المرحلة الأولى: إنستغرام، مع التوسع لاحقاً إلى تيك توك ويوتيوب.

## الرسالة

نشر الفائدة، وبناء جمهور ومجتمع مهتم بالمحتوى الإسلامي الصحيح: التذكير بالله، والقرآن الكريم، والأحاديث الصحيحة، والقصص الإسلامية، والسيرة النبوية، والأذكار، والدروس والقيم.
