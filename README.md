# مملكة ناصر

شركة ذكاء اصطناعي متخصصة في صناعة وإنتاج المحتوى الإسلامي الرقمي الهادف والموثوق.

المنصة الأساسية في المرحلة الأولى: إنستغرام، مع التوسع لاحقاً إلى تيك توك ويوتيوب.

## الرسالة

نشر الفائدة، وبناء جمهور ومجتمع مهتم بالمحتوى الإسلامي الصحيح: التذكير بالله، والقرآن الكريم، والأحاديث الصحيحة، والقصص الإسلامية، والسيرة النبوية، والأذكار، والدروس والقيم.

| المرحلة | الحالة |
|---|---|
| الأولى: وثائق التأسيس | منجزة |
| الثانية: الموقع العربي (لوحة المكتب المباشرة، ومحادثة المدير التنفيذي، وقاعدة البيانات) | منجزة وتعمل محلياً |

## المكتب الحي (دون أي دفع إضافي)

المكتب الأساسي للشركة صفحة خاصة على كلود، مصدرها `office/kingdom-office.html`. لا يفتحها إلا المالك. فيها:

- لوحة المكتب المباشرة، وقسم «يحتاج انتباهك».
- المحادثة مع المدير التنفيذي ياسين الركباني.
- تشغيل الموظفين فعلياً، كلٌّ حسب اختصاصه، مع تسجيل جلسات العمل الحقيقية.
- التقارير على القالب الموحّد، والإحاطة اليومية، والمراجعة الأسبوعية.

التشغيل يستخدم حساب المالك في كلود ضمن حدود خطته، دون مفتاح واجهة ودون أي دفع إضافي.

### المهام المجدولة

| المهمة | الموعد (بتوقيت باريس) | الإشعار |
|---|---|---|
| الإحاطة اليومية | يومياً 07:45 | إشعار على الهاتف |
| المراجعة الأسبوعية | الأحد 21:12 | إشعار على الهاتف |

تعمل هذه المهام في جلسات كلود السحابية، فتقرأ بيانات المكتب، وتحفظ التقرير فيه، ثم ترسل الإشعار.

## الموقع المحلي (اختياري، للمطورين)

يتطلب الإصدار 22.13 أو أحدث من بيئة "نود".

```bash
npm install
npm start
```

ثم افتح العنوان `http://localhost:3000` في المتصفح.

### تفعيل المدير التنفيذي (بعد موافقة المالك)

يحتاج المدير التنفيذي متغيّرين في بيئة التشغيل:

| المتغيّر | معناه |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاح واجهة كلود (سرّي، لا يُكتب في المستودع أبداً). |
| `KINGDOM_MODEL_ADVANCED` | معرّف النموذج المتقدم المستخدم للمدير التنفيذي. |

دون هذين المتغيّرين تُحفظ رسائل المالك، ويظهر تنبيه عربي بأن المدير التنفيذي غير مفعّل.

### تسجيل نشاط الموظفين

لوحة المكتب المباشرة تعرض النشاط المسجّل فقط. يُسجَّل النشاط عبر واجهة جلسات العمل في الخادم، أو عبر أداة سطر الأوامر:

```bash
npm run office -- start 2 --task 1 --status researching --note "مراجعة المصادر"
npm run office -- status 1 blocked --note "المصدر غير متاح"
npm run office -- end 1 --done
npm run office -- board
```
